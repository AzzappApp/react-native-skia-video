# Examples

Eight complete, tutorial-grade apps built on this library — each one a small,
documented codebase exercising a different part of the API. They share the
same stack (Expo, NativeWind, React Native Skia) and the same core idea: one
worklet renders both the live preview and the export.

```sh
git clone <repo> && cd <repo>
npm install && npx expo prebuild && npx expo run:ios   # or run:android
```

## Island Studio — a tiny video editor

<p align="center">
  <img src="/react-native-skia-video/img/island-studio.gif" width="240" alt="Island Studio demo" style={{ borderRadius: 16 }} />
</p>

[**mlecoq/react-native-video-editor**](https://github.com/mlecoq/react-native-video-editor)
— montage of gallery clips (up to 6), SkSL shader transitions between clips,
draggable/pinchable text and image overlays with enter/exit animations,
looping royalty-free soundtracks, hardware-encoded 1080×1920 export.

What it demonstrates best:

- **Timeline with transition overlap** — clips store durations; start times
  come from an accumulator that overlaps each clip with the previous one, and
  both live clips are handed to a transition shader
  ([`timeline.ts`](https://github.com/mlecoq/react-native-video-editor/blob/main/src/editor/timeline.ts)).
- **Transitions as SkSL shaders** — adding one is copy-pasting from
  [gl-transitions](https://gl-transitions.com/)
  ([`transitions.ts`](https://github.com/mlecoq/react-native-video-editor/blob/main/src/editor/transitions.ts)).
- **Gestures without React renders** — drags write into a shared value merged
  by the drawer on the UI thread
  ([`VideoPreview.tsx`](https://github.com/mlecoq/react-native-video-editor/blob/main/src/components/VideoPreview.tsx)).
- **Looping music** — chained `kind: 'audio'` items ([Audio guide](/docs/video-composition/audio)).

## Caption Studio — auto-captions

<p align="center">
  <img src="/react-native-skia-video/img/caption-studio.gif" width="240" alt="Caption Studio demo" style={{ borderRadius: 16 }} />
</p>

[**mlecoq/react-native-auto-captions**](https://github.com/mlecoq/react-native-auto-captions)
— burns animated, word-timed captions into any video. Parses Whisper
`verbose_json` (word timestamps), SRT or plain text; four caption styles
(word-by-word pop, karaoke color sweep, pill box, minimal); drag/pinch
placement; export keeps the original audio. The bundled sample carries a
real neural voice-over aligned with its transcript.

What it demonstrates best:

- **Time-driven text** — captions are a pure function of
  `(currentTime, transcript, settings)`
  ([`drawCaptions.ts`](https://github.com/mlecoq/react-native-auto-captions/blob/main/src/captions/drawCaptions.ts)).
- **Paragraph caching** — paragraphs are built once per *spoken word state*
  (highlights are styled text runs), never per frame
  ([`skiaCache.ts`](https://github.com/mlecoq/react-native-auto-captions/blob/main/src/editor/skiaCache.ts)).
- **Passing a video's own audio through** the preview and the export
  (`audio: true` on the video item).

## Wave Studio — a music visualizer

<p align="center">
  <img src="/react-native-skia-video/img/wave-studio.gif" width="240" alt="Wave Studio demo" style={{ borderRadius: 16 }} />
</p>

[**mlecoq/react-native-music-visualizer**](https://github.com/mlecoq/react-native-music-visualizer)
— flips the pipeline: the composition contains **no video items at all**,
just one audio item. Every pixel is generated from precomputed audio
analysis. Three scenes (radial spectrum ring, glowing oscilloscope,
audio-reactive SkSL shader clouds), color themes, custom artwork, 1080×1920
export with the track as its soundtrack.

What it demonstrates best:

- **Audio-only compositions** — the frames extractor drives the clock and
  plays the track; `frames` stays empty
  ([`composition.ts`](https://github.com/mlecoq/react-native-music-visualizer/blob/main/src/editor/composition.ts)).
- **Analysis as data, not DSP** — bass/mid/high envelopes, spectrum and
  waveform are precomputed per frame; the worklet just indexes the JSON
  ([`scripts/analyze-track.mjs`](https://github.com/mlecoq/react-native-music-visualizer/blob/main/scripts/analyze-track.mjs)).
- **Your own music, analyzed on-device** — pick any audio file:
  [react-native-audio-api](https://github.com/software-mansion/react-native-audio-api)
  decodes it to PCM and the exact same FFT pass runs on the phone, yielding
  to the UI under a progress bar — the visualizer can't tell a picked song
  from a bundled one
  ([`analyzeTrack.ts`](https://github.com/mlecoq/react-native-music-visualizer/blob/main/src/audio/analyzeTrack.ts)).
- **Audio bands as shader uniforms** — the Nebula scene is a full-screen
  SkSL shader whose warp deepens with the bass
  ([`scenes.ts`](https://github.com/mlecoq/react-native-music-visualizer/blob/main/src/visualizer/scenes.ts)).

## Frame Studio — a screen-recording beautifier

<p align="center">
  <img src="/react-native-skia-video/img/frame-studio.gif" width="240" alt="Frame Studio demo" style={{ borderRadius: 16 }} />
</p>

[**mlecoq/react-native-frame-studio**](https://github.com/mlecoq/react-native-frame-studio)
— gives any screen recording a product-demo look: wallpaper gradient
background, rounded shadowed frame, and cinematic tap-to-plant zooms that
ease in, hold and ease back out. The simplest engine of the series — no
text, no images, no audio analysis, just animated geometry over one video.

What it demonstrates best:

- **A camera as pure functions** — a zoom point plays out as
  *ease → hold → ease*; `getZoomAt(points, t)` returns the active transform
  and edge clamping keeps the wallpaper from leaking through
  ([`zoom.ts`](https://github.com/mlecoq/react-native-frame-studio/blob/main/src/editor/zoom.ts)).
- **One canvas transform inside a clip** — the frame never moves; the
  recording glides under a `clipRRect`
  ([`drawFrame.ts`](https://github.com/mlecoq/react-native-frame-studio/blob/main/src/editor/drawFrame.ts)).
- **Gestures and drawer sharing geometry** — the recording's placement is a
  pure function used by both the worklet and the tap handler
  ([`VideoPreview.tsx`](https://github.com/mlecoq/react-native-frame-studio/blob/main/src/components/VideoPreview.tsx)).

## Chroma Studio — a green-screen keyer

<p align="center">
  <img src="/react-native-skia-video/img/chroma-studio.gif" width="240" alt="Chroma Studio demo" style={{ borderRadius: 16 }} />
</p>

[**mlecoq/react-native-chroma-key**](https://github.com/mlecoq/react-native-chroma-key)
— removes the green screen from a video and composites it over a photo or a
looping video, with live keying controls. Ships an animated parrot-on-green
sample; the whole effect is one SkSL shader.

What it demonstrates best:

- **A video frame as a child shader** — the cover-fitted frame shader is
  handed to the keying effect via `makeShaderWithChildren`, which samples it
  per pixel
  ([`drawFrame.ts`](https://github.com/mlecoq/react-native-chroma-key/blob/main/src/editor/drawFrame.ts)).
- **Keying in the chroma plane** — colors are compared on the Cb/Cr axes of
  YCbCr, so brightness variations of the backdrop key out together;
  tolerance/softness/spill are plain uniforms
  ([`chromaKey.ts`](https://github.com/mlecoq/react-native-chroma-key/blob/main/src/editor/chromaKey.ts)).
- **Live uniforms without React renders** — dragging a slider writes a
  shared value the drawer reads on the next frame; release commits to state
  ([`KeySheet.tsx`](https://github.com/mlecoq/react-native-chroma-key/blob/main/src/components/sheets/KeySheet.tsx)).
- **Looping a background video by scheduling** — the same file repeated
  back-to-back in the composition, the drawer picking the active item
  ([`composition.ts`](https://github.com/mlecoq/react-native-chroma-key/blob/main/src/editor/composition.ts)).

## Privacy Studio — on-device face anonymization

<p align="center">
  <img src="/react-native-skia-video/img/privacy-studio.gif" width="240" alt="Privacy Studio demo" style={{ borderRadius: 16 }} />
</p>

[**mlecoq/react-native-privacy-studio**](https://github.com/mlecoq/react-native-privacy-studio)
— blurs, pixelates or emoji-covers every face in a video. Faces are detected
on-device (Apple Vision on iOS, ML Kit on Android — a 40-line local Expo
module — on frames pulled with `expo-video-thumbnails`), and the bundled
interview sample ships its face track as JSON — the exact shape the
on-device analysis produces.

What it demonstrates best:

- **Feeding ML output into the pipeline** — detection runs once when a video
  is picked (seconds, with a progress bar), producing plain JSON; playback
  and export just interpolate it
  ([`analyzeVideo.ts`](https://github.com/mlecoq/react-native-privacy-studio/blob/main/src/editor/analyzeVideo.ts)).
- **A local Expo Module when wrappers get in the way** — one JS API, Apple
  Vision behind it on iOS (simulator-friendly, no ML Kit pod), ML Kit on
  Android
  ([`modules/face-detector`](https://github.com/mlecoq/react-native-privacy-studio/tree/main/modules/face-detector)).
- **Detections become tracks** — a tiny greedy IoU tracker turns flickery
  per-frame boxes into stable per-person tracks that fade in and out; a pure
  worklet interpolates them at any playback time
  ([`faceTracks.ts`](https://github.com/mlecoq/react-native-privacy-studio/blob/main/src/editor/faceTracks.ts)).
- **Three effects from one clip** — the video shader redrawn through a blur
  image filter, a three-line pixelate SkSL, or a Twemoji PNG, clipped to
  each face
  ([`drawFrame.ts`](https://github.com/mlecoq/react-native-privacy-studio/blob/main/src/editor/drawFrame.ts)).

## Reframe Studio — landscape interviews into vertical shorts

<p align="center">
  <img src="/react-native-skia-video/img/reframe-studio.gif" width="240" alt="Reframe Studio demo" style={{ borderRadius: 16 }} />
</p>

[**mlecoq/react-native-reframe-studio**](https://github.com/mlecoq/react-native-reframe-studio)
— picks a moment out of a long landscape video, follows the speakers with a
virtual camera, transcribes the clip with Whisper **on the device** and
exports a captioned 9:16 short. It puts the face detection of Privacy
Studio and the caption engine of Caption Studio behind one pipeline.

What it demonstrates best:

- **Trimming is free** — `startTime` on the composition item tells the
  decoder where to begin, so a three-hour podcast costs exactly what a
  30-second clip costs. Picking the moment *before* analyzing is what keeps
  the on-device face pass — and the Whisper pass — proportional to the clip
  you keep
  ([`composition.ts`](https://github.com/mlecoq/react-native-reframe-studio/blob/main/src/editor/composition.ts)).
- **A picker that listens** — the audio track is decoded to a plain loudness
  envelope ([react-native-audio-api](https://github.com/software-mansion/react-native-audio-api)):
  waveform under the filmstrip, released handles snap to the nearest pause
  so a clip never starts mid-word, and the most talkative windows are
  offered as one-tap suggested moments
  ([`moments.ts`](https://github.com/mlecoq/react-native-reframe-studio/blob/main/src/editor/moments.ts)).
- **True auto-captions** — whisper.cpp transcribes the segment on the phone;
  token timestamps are glued back into words and grouped into caption-sized
  phrases, all pure functions
  ([`transcribe.ts`](https://github.com/mlecoq/react-native-reframe-studio/blob/main/src/captions/transcribe.ts)).
- **A camera path, not camera math** — dead zone, eased follow with a speed
  cap, cuts (never pans) when focus moves to another person, a statue filter
  for face-shaped things that never move: decisions that read better as a JS
  loop run once after the analysis. The worklet only interpolates the
  result, and never across a cut
  ([`camera.ts`](https://github.com/mlecoq/react-native-reframe-studio/blob/main/src/editor/camera.ts)).
- **Two spaces that never meet** — the camera works in source space, the
  captions in output space, drawn after the crop transform is restored; the
  caption engine doesn't even know the video was cropped
  ([`drawFrame.ts`](https://github.com/mlecoq/react-native-reframe-studio/blob/main/src/editor/drawFrame.ts)).

## Retro Studio — VHS, Super 8, CRT and Game Boy filters

<p align="center">
  <img src="/react-native-skia-video/img/retro-studio.gif" width="240" alt="Retro Studio demo" style={{ borderRadius: 16 }} />
</p>

[**mlecoq/react-native-retro-studio**](https://github.com/mlecoq/react-native-retro-studio)
— gives any video the look of another decade. Four eras, each implemented as
**one SkSL shader** over the video frame, tuned live with two sliders and
burned in at export. The purest shader tutorial of the series: no analysis
pass, no models, no waiting — pick a video, tap an era, export.

What it demonstrates best:

- **The video frame as a child shader** — `drawFrame` cover-fits the frame
  into a shader and hands it to the era's effect via
  `makeShaderWithChildren`, so the filter samples the source per output
  pixel: VHS displaces whole scanlines, CRT bends the entire picture,
  Game Boy resamples it into fat pixels — no intermediate surface
  ([`drawFrame.ts`](https://github.com/mlecoq/react-native-retro-studio/blob/main/src/editor/drawFrame.ts)).
- **Filters as data** — an era is a string of SkSL plus a name and a knob
  definition; all four share the same uniforms, so switching era compiles a
  different string, cached per worklet runtime
  ([`filters.ts`](https://github.com/mlecoq/react-native-retro-studio/blob/main/src/filters/filters.ts)).
- **Time as a uniform** — the tracking band crawls, the film gate weaves,
  the projector lamp flickers, grain and dust refresh, all from the one
  `time` uniform the drawer already receives; randomness is a `hash()` in
  the shader, and Super 8 quantizes time to 18fps first because that's how
  the projector ran.
- **A camcorder OSD with zero fonts** — "PLAY ▶" and the tape counter are
  seven-segment characters built from plain `drawRect` calls, crisp at any
  export size
  ([`osd.ts`](https://github.com/mlecoq/react-native-retro-studio/blob/main/src/editor/osd.ts)).

## Patterns shared by all eight

- **One worklet for preview and export** — what you see is exactly what you
  save; there is no second rendering path to keep in sync.
- **Resolution independence** — all geometry lives in fractions of the
  canvas, so the small preview and the full-size export render the same
  composition.
- **Assets across worklet runtimes** — images travel as raw `Uint8Array`s
  and each runtime decodes its own `SkImage`s; the Skia typeface provider is
  created once on the JS thread and captured by the worklets. Skia objects
  built inside a runtime (paragraphs, compiled shaders) are cached per
  runtime on `globalThis`.
- **Worklet helpers are defined before their callers** — closures are
  captured at the definition site; a helper declared further down the file
  would be captured uninitialized and crash at runtime.
- **Version matrix** — the examples track the combination shipped in
  production by Azzapp: `@shopify/react-native-skia` 2.10.x, Reanimated 4.5,
  skia-video 0.10.
