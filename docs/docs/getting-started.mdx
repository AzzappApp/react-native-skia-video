# Getting Started

**React Native Skia Video** adds video superpowers to
[React Native Skia](https://shopify.github.io/react-native-skia/): it decodes
videos straight into **GPU textures** you can draw with the Skia canvas API,
lets you **compose** multiple videos (and anything Skia can draw) frame by
frame, and **exports** the result through the platform's hardware encoders —
with audio mixed in.

It powers the cover editor of [Azzapp](https://azzapp.com), where every cover
video is composited and encoded on-device with this library.

:::warning Beta
The library is still in beta. The API is stable in practice but may evolve
between minor versions.
:::

## Installation

```sh
npm install @azzapp/react-native-skia-video react-native-skia react-native-webgpu
```

The library relies on the following peer dependencies:

| Package | Version |
| --- | --- |
| `react-native-skia` | `>= 3.2.0` |
| `react-native-webgpu` | `>= 0.13.0` |
| `react-native-reanimated` | `>= 4.0.0` |
| `react-native-worklets` | `>= 0.10.0` |

React Native Skia v3 renders with Graphite on WebGPU (Dawn): video frames are
exchanged with Skia as WebGPU textures on the GPU device that Skia and
[React Native WebGPU](https://wcandillon.github.io/react-native-webgpu/)
share. Pick versions of the two packages built against the same Dawn release
(see their
[compatibility table](https://wcandillon.github.io/react-native-webgpu/docs/integrations/react-native-skia)).
Android requires API level 28 or above, iOS 15.1 or above.

:::info React Native Skia v2
For `@shopify/react-native-skia` v2, use the 0.x releases of this library.
:::

It ships native code for **iOS** (AVFoundation, IOSurface) and **Android**
(MediaCodec, OpenGL ES and AHardwareBuffer). With Expo, use a
[development build](https://docs.expo.dev/develop/development-builds/introduction/)
(`npx expo prebuild && npx expo run:ios`) — Expo Go can't load custom native
modules.

## Three building blocks

### 1. Play a single video

The [`useVideoPlayer`](/docs/video-player) hook decodes a video file and hands
you its current frame as a Reanimated shared value, with a ready-to-draw
`SkImage`:

```tsx
import { Canvas, Image } from 'react-native-skia';
import { useVideoPlayer } from '@azzapp/react-native-skia-video';
import { useDerivedValue } from 'react-native-reanimated';

const MyVideoPlayer = ({ uri, width, height }) => {
  const { currentFrame } = useVideoPlayer({ uri, autoPlay: true });

  const videoImage = useDerivedValue(() => currentFrame.value?.image ?? null);

  return (
    <Canvas style={{ width, height }}>
      <Image image={videoImage} x={0} y={0} width={width} height={height} fit="cover" />
    </Canvas>
  );
};
```

### 2. Compose multiple videos

A [`VideoComposition`](/docs/video-composition) describes which media plays
when; a `drawFrame` worklet receives the decoded frames of every active video
each vsync and draws the result with the Skia canvas —
[`useVideoCompositionPlayer`](/docs/video-composition/playback) takes care of
the rest.

### 3. Export to a file

[`exportVideoComposition`](/docs/video-composition/exporting) replays the
**same** `drawFrame` worklet on a background thread, feeding each rendered
frame to the hardware encoder. Preview and export can never drift apart.
